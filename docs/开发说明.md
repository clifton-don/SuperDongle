# SuperDongle

基于 **ESP32-S3** 的多功能物联网硬件固件，支持 WiFi 配网、USB 大容量存储、远程文件管理和 OTA 升级。

## 项目简介

SuperDongle 是一个插入电脑 USB 即可使用的智能硬件，主要功能包括：

- **WiFi 配网**：AP 热点直连配网 + STA 路由器连接，已保存 WiFi 自动重连
- **USB 大容量存储**：通过 TinyUSB 将 SD 卡暴露为 U 盘，支持 Windows/macOS/Linux
- **无线文件管理**：通过 Web 页面浏览、上传、下载、管理 SD 卡文件
- **OTA 远程升级**：固件 + SPIFFS 网页文件双分区 OTA 更新
- **LED 状态指示**：WS2812 RGB LED 显示设备状态
- **HID 通信**：支持 HID 协议通信功能

## 开发环境

- **芯片**：ESP32-S3（双核 240MHz）
- **开发框架**：ESP-IDF 5.5.4
- **Flash**：16MB，QIO 80MHz
- **PSRAM**：8MB，OCT 80MHz
- **固件版本**：v1.0.0

## 快速开始

1. 安装 ESP-IDF 5.5.4 开发环境
2. 使用 VS Code 打开项目
3. 通过 ESP-IDF 插件工具栏编译并烧录
4. 连接 `SuperDongle` WiFi 热点（密码 `12345678`）
5. 访问 `http://192.168.5.1` 或 `http://superdongle.local` 进入管理页面

## 代码协作开发规范

### 分支管理流程

```
1. 克隆项目到本地
   git clone <仓库地址>
   cd SuperDongle

2. 切换到 develop 分支
   git checkout develop

3. 从 develop 新建本地分支（feature/bugfix/hotfix）
   git checkout -b feature/xxx
   git checkout -b bugfix/xxx
   git checkout -b hotfix/xxx

4. 开发完成后提交到本地分支
   git add .
   git commit -m "提交信息"

5. 拉取远程最新代码
   git pull origin develop

6. 解决冲突（如有）
   # 手动解决冲突文件后
   git add .
   git commit -m "merge: 解决冲突"

7. 推送分支到远程
   git push origin <本地分支名>

8. 创建 Pull Request 到 develop 分支
```

### Commit 信息规范

**格式**：`[类型][大目录][功能]: 内容描述`

**常用类型**：

| 类型 | 含义 |
|------|------|
| `feat` | 新增功能 |
| `fix` | 修复 bug |
| `docs` | 文档修改 |
| `refactor` | 代码重构（无功能变化） |
| `style` | 格式、注释调整（不影响代码逻辑） |
| `test` | 新增/修改测试代码 |
| `chore` | 构建工具、依赖更新等杂项 |

**示例**：

```
[feat][main/wifi_manager]: 添加 WiFi 自动重连功能
[fix][main/web_module]: 修复 API 响应超时问题
[docs][docs]: 更新前端接口文档
[refactor][main/storage_module]: 优化文件读写逻辑
[style][main]: 统一代码缩进格式
[test][main]: 添加 WiFi 模块单元测试
[chore]: 更新 ESP-IDF 依赖版本
```
